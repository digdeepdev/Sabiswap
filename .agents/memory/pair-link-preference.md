---
name: Pair-link preference
description: User-approved format for shareable SabiSwap pair links.
---

Use clean `sabiswap.io/<from>/<to>` swap-pair links, like SideShift’s `sideshift.ai/eth/sol`, rather than query-only asset links.

**Why:** The user explicitly requested this format and confirmed replacing the original query-style links.

**How to apply:** Preserve this format when changing swap navigation or sharing. Network qualifiers may remain query parameters where necessary to distinguish chains.
